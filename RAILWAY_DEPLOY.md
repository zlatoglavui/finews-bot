# 🚀 Запуск Financial News Bot на Railway

Пошаговая инструкция — от нуля до работающего бота.

---

## Шаг 1 — Подготовь Telegram

### 1.1 Создай бота

1. Открой Telegram, найди **@BotFather**
2. Напиши `/newbot`
3. Введи название (например: `Finance News Bot`)
4. Введи username (например: `my_finance_news_bot`)
5. BotFather пришлёт токен вида:
   ```
   7123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```
   **Сохрани его** — это `TELEGRAM_BOT_TOKEN`

### 1.2 Создай или используй существующий канал

1. Создай публичный канал в Telegram (или используй существующий)
2. Username канала — это `TELEGRAM_CHANNEL_ID`, например `@my_finance_channel`
3. Зайди в настройки канала → **Администраторы** → **Добавить администратора**
4. Найди своего бота по username и добавь его с правом **"Публикация сообщений"** ✅

### 1.3 Проверь что бот стал админом

Напиши в канале что-нибудь от своего имени — это подтвердит что канал работает.

---

## Шаг 2 — Получи ключ Anthropic API

1. Зайди на [console.anthropic.com](https://console.anthropic.com)
2. Зарегистрируйся или войди
3. **API Keys** → **Create Key**
4. Скопируй ключ вида:
   ```
   sk-ant-api03-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```
   **Сохрани его** — это `ANTHROPIC_API_KEY`

> ⚠️ На новом аккаунте Anthropic даёт $5 бесплатных кредитов. Бот тратит ~$0.002 за статью, так что первые ~2500 статей бесплатно.

---

## Шаг 3 — Залей код на GitHub

### 3.1 Создай репозиторий

1. Зайди на [github.com](https://github.com) → **New repository**
2. Название: `finews-bot` (любое)
3. Видимость: **Private** (рекомендуется, т.к. содержит конфиги)
4. Нажми **Create repository**

### 3.2 Залей файлы

**Если у тебя установлен Git:**
```bash
cd finews_bot          # папка с проектом
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/ТВО_ИМЯ/finews-bot.git
git push -u origin main
```

**Если Git не установлен — через браузер:**
1. На странице репозитория нажми **"uploading an existing file"**
2. Перетащи все файлы проекта в браузер
3. Нажми **"Commit changes"**

> Важно: файл `.env` **НЕ заливай** на GitHub (он в `.gitignore`). Переменные вводятся прямо в Railway.

---

## Шаг 4 — Задеплой на Railway

### 4.1 Создай аккаунт

1. Зайди на [railway.app](https://railway.app)
2. Нажми **"Login"** → **"Login with GitHub"**
3. Авторизуй Railway доступ к твоим репозиториям

### 4.2 Создай проект

1. На дашборде нажми **"New Project"**
2. Выбери **"Deploy from GitHub repo"**
3. Найди и выбери репозиторий `finews-bot`
4. Railway автоматически найдёт `Dockerfile` и начнёт сборку

### 4.3 Дождись первой (неудачной) сборки

Первый деплой упадёт с ошибкой — это нормально, потому что переменные окружения ещё не заданы. Увидишь в логах:
```
Отсутствуют обязательные переменные окружения: ['TELEGRAM_BOT_TOKEN', ...]
```
Это ожидаемо, переходи к следующему шагу.

---

## Шаг 5 — Добавь переменные окружения

1. Кликни на твой сервис в Railway
2. Перейди во вкладку **"Variables"**
3. Нажми **"New Variable"** и добавь по одной:

| Имя переменной | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен от BotFather (шаг 1.1) |
| `TELEGRAM_CHANNEL_ID` | `@username_канала` |
| `ANTHROPIC_API_KEY` | Ключ от Anthropic (шаг 2) |
| `FETCH_INTERVAL_MINUTES` | `10` |
| `MAX_POSTS_PER_DAY` | `15` |
| `POST_INTERVAL_MINUTES` | `72` |
| `SIMILARITY_THRESHOLD` | `0.85` |
| `LOG_LEVEL` | `INFO` |

4. После добавления всех переменных Railway автоматически перезапустит деплой

---

## Шаг 6 — Подключи Volume для базы данных

> Без этого шага база данных **сотрётся** при каждом редеплое!

1. Кликни на твой сервис
2. Перейди во вкладку **"Settings"**
3. Найди секцию **"Volumes"** → нажми **"Add Volume"**
4. Заполни:
   - **Mount Path**: `/app/data`
5. Нажми **"Add"**
6. Railway перезапустит сервис с подключённым хранилищем

### 7.1 Смотри логи

1. Кликни на сервис → вкладка **"Deploy Logs"**
2. Должно появиться:

## Что делать если что-то пошло не так

### ❌ "Нет доступа к каналу"
→ Бот не является администратором канала. Повтори шаг 1.2.

### ❌ "TELEGRAM_BOT_TOKEN не задан"
→ Переменная не добавлена в Railway Variables. Повтори шаг 5.

### ❌ "Markdown ошибка"
→ Это не критично, бот автоматически отправит без форматирования.

### ❌ "Rate limit Anthropic API"
→ Нет денег на балансе Anthropic. Пополни на [console.anthropic.com](https://console.anthropic.com).

### ❌ Бот работает, но постов нет
→ Все новости отфильтровались как нерелевантные. Нормально если источники сейчас не пишут про нужные темы — следующий цикл через 10 минут.

## Стоимость Railway

- **Hobby план**: $5/месяц фиксированно + usage
- Бот практически не потребляет ресурсов (~50MB RAM, <0.1 CPU)
- Реальная стоимость: **~$5-7/месяц** всё включено

## Управление ботом

**Остановить:**
Railway → сервис → кнопка паузы (⏸)

**Обновить код:**
```bash
git add . && git commit -m "update" && git push
```
Railway автоматически пересоберёт и задеплоит.

**Изменить источники или ключевые слова:**
Правь `config/sources.json` → делай git push.

**Изменить формат поста:**
Правь `SYSTEM_PROMPT` в `src/ai/processor.py` → делай git push.
